# Expresto – Assistive Communication App

Expresto is an assistive communication application designed to help hard-of-hearing individuals communicate more effectively in daily life and emergency situations.

The application aims to reduce communication barriers using sign-to-text and text-to-sign translation features.

---

## Problem Statement

Communication can be challenging for hard-of-hearing individuals, especially when interacting with people unfamiliar with sign language.

In emergency situations, traditional communication methods may not always be practical or efficient.

Expresto was developed to provide a faster and more accessible communication experience.

---

## Features

- Sign-to-text translation
- Text-to-sign translation using avatar-based output
- Real-time communication support
- Accessibility-focused interface
- User-friendly design

---

## Tech Stack

### Frontend
- Flutter

### Machine Learning
- Transformer-based Sign Recognition Model

### Dataset
- IIT Bombay Sign Language Dataset


---

## System Workflow

1. User performs sign gestures
2. Input gesture sequence is captured
3. Transformer model processes the sequence
4. Signs are translated into text
5. Text can also be converted into avatar-based sign output
